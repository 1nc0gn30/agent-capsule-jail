How the jail works
Linux only

      

        

          
bubblewrap namespaces

          
--ro-bind / / read-only root; private tmpfs on /home, /root, /run, /tmp; --unshare-all (no network unless the operator sets CAPSULE_ALLOW_NETWORK=1), --cap-drop ALL, --die-with-parent.

        

        

          
Resource bounds

          
prlimit caps wall timeout, address space, file size and processes. When systemd user scopes are available the process cap is a cgroup TasksMax; otherwise RLIMIT_NPROC. The engine strip shows which one is active.

        

        

          
Secret stripping

          
The capsule starts from a minimal environment. Variables that look like credentials (API keys, tokens, secrets) are never passed in, and refused allowlist names come back in env_denied.

        

        

          
Diff + receipt

          
The scratch directory is hashed before and after the run. The daemon returns receipt_sha256 over the command, exit code, output and diff; this page recomputes it with WebCrypto.
